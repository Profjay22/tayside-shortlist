# Tayside Shortlist

A generated page listing currently-open jobs within reach of Dundee.

Rebuilt automatically four times a day by a private scanner that searches
NHS Scotland Jobtrain, myjobscotland, jobs.ac.uk and Adzuna. This repository
holds only the published output. It contains no personal data and no
credentials, just links to public job adverts.

Page: https://profjay22.github.io/tayside-shortlist/
